# Test Vocacional de Programación

## Documentación Interna del Proyecto

### _**Tecnologías Utilizadas**_**:**&#x20;

#### _Backend_

* Java
* Spring Boot
* Mysql

#### _Frontend_

* HTML
* CSS&#x20;
* Bootstrap
* JavaScript

_Descripción General_: Aplicación web que permite la gestión de un sistema de test vocacional, facilitando el registro de alumnos y la visualización de sus resultados en base a un cuestionario vocacional. La aplicación presenta formularios para el ingreso de datos y la posibilidad de exportar los registros en formato Excel.&#x20;

### Documentación de Procesos

### **Requisitos del Producto**

La aplicación de gestión de test vocacional debe cumplir con los siguientes requisitos:

* Permitir el registro de alumnos de manera sencilla.
* Facilitar la visualización de resultados basados en cuestionarios vocacionales.
* Proveer formularios intuitivos para el ingreso de datos.
* Ofrecer exportación de datos en formato Excel para facilitar el análisis fuera de la plataforma.
